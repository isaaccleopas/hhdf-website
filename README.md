# Hope Healing and Development Foundation

Static website for HHDF, based on the foundation’s About Us document.

## Live preview

Deployment is **paused** (GitHub Pages disabled and the public githack preview link is offline).

The full website is preserved on the `site-live` branch for when you are ready to redeploy.

To preview locally, check out `site-live` or restore `index.html` from that branch, then run the Elixir server below and open [http://localhost:4000](http://localhost:4000).

Repository: https://github.com/isaaccleopas/hhdf-website

## Run locally with Elixir

```bash
mix deps.get
mix run --no-halt
```

Then open [http://localhost:4000](http://localhost:4000).
